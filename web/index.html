Free, without a catch.

The work happens on your computer. There are no conversion credits, accounts, or paid APIs. Engines download only when needed, so the first conversion can take a little longer.

A few honest limits.

Formats are containers, not magic. Some conversions drop layout, metadata, layers, or precision. Large files may exceed your device’s memory. The note above the convert button explains each route.

What about formats that need more than a browser?

Legacy binary Word (.doc), legacy PowerPoint (.ppt), DWG, SolidWorks parts, encrypted PDFs, vendor instrument project files, and DRM-protected ebooks need specialized tools. They are not advertised as working web conversions. The desktop app adds LibreOffice support for legacy Office files and more memory for large media.

For archival or proprietary scientific data, export an open exchange format from the instrument software first. Converting diffraction data does not turn it into a crystal structure.
