Limits

Files can be up to 128 MiB each. The first conversion downloads the required engine; large files may exceed the browser’s memory.

Conversions can change page layout, metadata, layers, or numeric precision. Legacy DOC/PPT files, native CAD files, encrypted files, and some instrument formats require desktop software.
